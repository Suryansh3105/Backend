# HTTP Server Task

### Description

Build a simple HTTP Server with following features.

💡

GET: / : Send simple hello from server message.

GET: /contact-us : Send your email and contact number to the user.

POST: /tweet : Do a fake DB operation and send the ack that it is done.

GET: /tweet : Send all the tweets from fake DB to the user.

Also, you need to log the incoming requests with timestamps in file named log.txt.
